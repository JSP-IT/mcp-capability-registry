# Security Policy

Please report suspected vulnerabilities privately through GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Please do not open public issues for security problems.

The project is offline-only in v0.1.0:

- It does not connect to MCP servers.
- It does not execute MCP tools or prompts.
- It replaces the values of common credential-like keys with `[REDACTED]` in normalized reports.
- Free-form description and metadata text should still be reviewed for sensitive content.
